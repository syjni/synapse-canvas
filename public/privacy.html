개인정보처리방침

Dendra (https://dendra.pages.dev) · 시행일 2026-11-01

1. 기본: 기기에만 저장

Dendra는 동기화를 켜지 않으면 작성한 맵(글 상자, 사진, 그림, 연결선, 카테고리)과 설정을 사용 중인 기기의 브라우저 저장소(IndexedDB)에만 저장합니다. 이 경우 어떤 정보도 서버로 보내지 않습니다.

2. 동기화를 켠 경우

설정에서 동기화를 켜면 여러 기기에서 같은 맵을 쓰기 위해 아래 정보를 Supabase 서버(운영자가 만든 프로젝트)에 저장합니다.

아이디·비밀번호직접 정한 아이디와 비밀번호(비밀번호는 Supabase가 해시로만 보관). 아이디는 서버 내부에서 아이디@users.synapse.invalid 형태로 바꿔 저장하며, 실제 이메일이 아닙니다.
기기 열쇠연결한 기기마다 만들어지는 익명 사용자 식별자, 기기 이름(직접 입력 또는 "iPhone Safari"처럼 자동 생성), 연결 시각, 마지막 접속 시각
맵 데이터카테고리, 글 상자 내용, 위치·크기, 연결선, 펜 그림, 수정·삭제 시각, 화면 설정(색상 등)
사진상자에 넣은 사진(긴 변 1200px로 줄인 JPEG)

스팸 가입을 막기 위해 아이디 만들기·로그인·기기 연결 시 Cloudflare Turnstile(사람 확인)을 사용합니다. 이 과정에서 Cloudflare가 브라우저 정보를 처리할 수 있습니다.

3. 수집하지 않는 정보

  • 이메일 주소, 전화번호, 이름 등 다른 개인정보는 받지 않습니다.
  • 광고·분석 도구, 추적 쿠키를 쓰지 않습니다.

4. 접근 범위

서버 데이터는 행 수준 보안(RLS)으로 보호되어, 같은 보관함에 연결된 열쇠(내 아이디와 내가 연결한 기기)만 읽고 쓸 수 있습니다. 사진 저장소는 비공개입니다.

5. 보관 기간과 삭제

  • 삭제한 항목의 기록(기기 간 삭제를 맞추기 위한 표시)은 30일 뒤 정리됩니다.
  • 설정 → 동기화 → 로그아웃: 그 기기의 열쇠가 삭제되어 더 이상 서버에 접근할 수 없습니다. 이 기기 데이터를 유지할지 지울지 고를 수 있습니다. 다른 기기의 연결된 기기 목록에서 해제해도 같습니다.
  • 설정 → 동기화 → 계정 삭제: 보관함, 서버의 맵 데이터, 사진, 아이디·기기 열쇠가 모두 삭제됩니다. 각 기기 안의 데이터는 그대로 남으며, 앱 안에서 지울 수 있습니다(브라우저의 사이트 데이터 삭제).
