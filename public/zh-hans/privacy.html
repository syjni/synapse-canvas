隐私政策

PixieMap (https://pixiemap.pages.dev) · 生效日期 2026-10-31

本文为韩语原文的译文。如有不一致，以韩语版本为准。

1. 默认：只保存在设备上

如果不开启同步，PixieMap 会把你创建的导图 (文本框、照片、绘画、连线、分类) 和设置只保存在当前设备的浏览器存储 (IndexedDB) 中。此时不会向服务器发送任何信息。

登录或关联设备时，如果这台设备上有自己的内容，会询问是添加到账号，还是只使用账号内容。在你选择之前，不会把这台设备的内容发送到服务器。如果选择只使用账号内容，切换前这台设备上的数据 (含照片) 会作为备份只保留在这台设备上 (保留最近 3 份)，不会发送到服务器。

2. 开启同步时

在设置中开启同步后，为了在多台设备上使用同一份导图，会把以下信息保存到 Supabase 服务器 (运营者创建的项目，位于日本东京区域)。关于跨境传输，请参阅第 3 条。

用户名与密码你自己设定的用户名和密码 (密码仅由 Supabase 以哈希形式保存)。用户名在服务器内部会转换为 用户名@users.synapse.invalid 的形式保存，这不是真实的电子邮件地址。
设备密钥为每台已关联设备生成的匿名用户标识、设备名称 (手动输入，或自动生成，例如“iPhone Safari”)、关联时间、上次在线时间
导图数据分类、方框 (文字内容、位置、大小)、连线、笔迹、修改和删除时间、设置 (颜色等)
照片放入方框的照片 (长边缩小到 1200px 的 JPEG)

为防止机器人 (自动注册)，在创建用户名、登录和关联设备时使用 Cloudflare Turnstile (人机验证)。在此过程中，Cloudflare 会处理 IP 地址和浏览器信息 (第 3 条)。

3. 个人信息的跨境传输

只有在开启同步时，个人信息才会按以下方式传输到境外。

接收方Supabase, Inc.
个人信息咨询：privacy@supabase.com (Supabase 官方隐私咨询邮箱)
接收国家日本 (Supabase 东京区域，ap-northeast-1)
传输项目用户名、导图数据 (分类、方框、连线、笔迹、设置)、附带的照片、设备名称
传输时间与方式开启同步后，每次发生更改时通过加密网络 (HTTPS) 传输
使用目的设备间同步
保存期限直到注销账号为止。注销账号后会立即从服务器删除。
拒绝方式及影响不开启同步就不会发生跨境传输，所有数据都只保存在设备上。不开启同步也能使用应用的全部功能，只是无法与其他设备保持一致。

为防止机器人 (人机验证)，按以下方式使用 Cloudflare Turnstile。

接收方Cloudflare, Inc.
个人信息咨询：privacyquestions@cloudflare.com
接收国家美国等 Cloudflare 运营所在的国家
传输项目IP 地址、浏览器和设备信息 (用于人机验证)
传输时间与方式在创建用户名、登录、关联设备的页面进行人机验证时，通过加密网络 (HTTPS) 传输
使用目的防止自动注册、暴力破解登录等机器人行为
保存期限依照 Cloudflare 的隐私政策
拒绝方式及影响不开启同步就不会进行人机验证。此时无法使用同步。

4. 不收集的信息

  • 不收集电子邮件地址、电话号码、姓名等其他个人信息。
  • 不使用广告、分析工具或跟踪 Cookie。

5. 访问范围

服务器数据受行级安全 (RLS) 保护，只有关联到同一同步库的密钥 (你的用户名和你关联的设备) 才能读写。照片存储为非公开。

6. 保存期限与删除

  • 已删除项目的记录 (用于在设备间同步删除操作的标记) 会在 30 天后清理。
  • 选择“只使用账号内容”时留在这台设备上的备份，会在 30 天后自动删除。在此之前，可以在 设置 → 同步 → 恢复之前的数据 中添加到账号。退出登录时如果选择清除这台设备的数据，备份也会一并删除。
  • 设置 → 同步 → 退出登录：这台设备的密钥会被删除，之后无法再访问服务器。可以选择保留或清除这台设备的数据。在其他设备的已关联设备列表中移除也是同样效果。
  • 设置 → 同步 → 注销账号：同步库、服务器上的导图数据、照片、用户名和设备密钥会全部删除。各设备中的数据会保留，可以在浏览器中删除 (清除网站数据)。
